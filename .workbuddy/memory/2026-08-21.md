
## Docker 配置对抗性审查（2026-08-21）
对 docker-compose.yml + 3 个 Dockerfile + nginx 配置做了对抗性审查，产出风险矩阵（16 项发现）。
关键结论：
- P0/P1：BOOTSTRAP_ADMIN_PASSWORD=admin123456 与 JWT_SECRET_KEY=change-me 均在 .env 中未改（代码有兜底但重启掉登录态）；5432/6379 端口映射 0.0.0.0 且无密码；API 密钥明文入容器 env（Tavily 是 tvly-dev-* 开发密钥）
- P2：8001 直连后端绕过 nginx；backend/worker root 运行无 cap_drop；无资源限制/Redis 无 maxmemory；nginx 无安全头/无 TLS
- P3：镜像 tag 浮动未 pin；日志无轮转/DB 无备份；alembic 无迁移锁 + uvicorn 单 worker
- 验证通过项：docker compose config 合法、BuildKit lint 零警告、dockerignore 实测无误伤 frontend/package.json、alembic env.py 正确读取容器内 DATABASE_URL、.env 未被 git 跟踪、依赖全 pin
- 修复优先级：先改 .env 凭据 → 收紧端口暴露 → 非 root + 资源限制 → nginx 安全头/TLS → pin tag
