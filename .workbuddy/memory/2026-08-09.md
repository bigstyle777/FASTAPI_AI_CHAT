## SPA 路由代理冲突修复（18:47）
- **问题**: 刷新 /chat、/admin 页面时 Vite 代理将前端路由转发到后端，返回 `{"detail":"Not Found"}`
- **根因**: Vite proxy 是前缀匹配，`/chat` 规则将所有 `/chat*` 请求代理到后端，Vue Router 无法处理
- **修复**: 自定义 spaFallbackPlugin 插件，通过 configureServer 注入中间件：
  - 带子路径（`/users/`、`/chat/`、`/admin/`）→ API 请求，放行给代理
  - 无扩展名的 GET 请求 → SPA 路由，改写为 `/index.html`
- **第二次修复（18:51）**: 改用 `configureServer` 自定义中间件改写 SPA 路由 → 但条件太宽（`!url.includes('.')`）把 `/@vite/client` 等 Vite 内部路径也改写了，导致 dev server 彻底挂掉
- **第三次修复（18:56）**: 改为精确匹配已知 SPA 路由集合 `['/', '/chat', '/login', '/profile', '/admin']`，不再影响 Vite 内部路径和 API 代理
- **验证**: 所有 SPA 路由(200)、API 代理(401/405)、Vite 内部路径(200) 全部正常
