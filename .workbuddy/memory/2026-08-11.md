# 2026-08-11 工作日志

## RAG 上传 422 修复
- 问题：前端拖拽/点击上传文件到 `/rag/upload` 返回 422 Unprocessable Content，后端无报错，UI 无任何反馈。
- 根因：`frontend/src/api/client.ts` 的 `apiCall` 默认强制加 `Content-Type: application/json`，而 `uploadDocument` 用 `FormData` 作为 body。浏览器被错误的内容类型误导，FastAPI 按 JSON 解析 multipart 失败 → 422。
- 修复：`apiCall` 中当 `options.body instanceof FormData` 时不设置 JSON Content-Type，让浏览器自动设置 `multipart/form-data; boundary=...`。`uploadDocument` 传 `headers: {}` 即可。
- 验证：`vue-tsc --noEmit` 通过。dev server HMR 已生效。
